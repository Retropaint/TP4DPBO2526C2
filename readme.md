# TP4

## Design & Function

This is a GUI program made with Java Swing. No IDE was used.

Structure:

- `Person` class, consisting of :
    - `id`
    - `name`
    - `age`
    - `email`
- Each attribute above is given an input field
- 3 actions are provided:
    - `ADD` - adds a new person with the specified inputs
    - `DELETE` - deletes the person with the associated ID (if they exist)
      (shows dialog before doing so)
    - `UPDATE` - updates the person's data with the associated ID
